Scheduled assessments

Automate recurring assessments with cron / Task Scheduler using the CLI:

# Daily full assessment at 02:00 (Linux cron)
0 2 * * * cd /opt/sentinel && python src/main.py audit --all --target 10.0.0.10

# Windows Task Scheduler (PowerShell)
schtasks /Create /SC DAILY /TN "SentinelAudit" /TR "python C:\sentinel\src\main.py audit --all" /ST 02:00
